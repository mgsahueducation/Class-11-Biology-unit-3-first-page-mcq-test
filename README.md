## 📖 About

A **single-file interactive quiz** built for **NEET (National Eligibility cum Entrance Test)** aspirants.  
Covers **Unit 3 — Cell: Structure and Functions** from the NCERT Biology syllabus.

| Chapter | Topic |
|---------|-------|
| **Ch. 8** | Cell: The Unit of Life |
| **Ch. 9** | Biomolecules |
| **Ch. 10** | Cell Cycle and Cell Division |

---

## ✨ Features

- 🎯 **12 carefully curated MCQs** from previous NEET papers & NCERT concepts  
- ✅ **Instant feedback** — green for correct, red for wrong  
- 💡 **Explanation box** appears after every answer for deep learning  
- ⬅️➡️ **Previous / Next navigation** — learn at your own pace  
- 📊 **Live score tracking** — updates as you answer  
- 🔄 **Reset button** — restart the quiz anytime  
- 📱 **Fully responsive** — works on mobile, tablet, and desktop  
- ⚡ **Zero dependencies** — pure HTML, CSS & JavaScript  
- 🌐 **Single file** — just `index.html`, no build step needed
